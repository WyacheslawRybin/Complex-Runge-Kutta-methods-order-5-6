# Complex-Runge-Kutta-methods-order-5-6
NumPy script that tunes Runge–Kutta methods with complex coefficients and real projection (CRK5, CRK6, complex Cash–Karp pair CCK6(5) and cascade) to a given ODE problem. It moves the tableau along the solution set of the order conditions, keeps the order of every level exact and minimizes the global error. Code for the paper by Rybin et al.
